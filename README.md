# dear-hamin

하민이를 위한 생일 책 웹사이트.

## GitHub Pages
`index.html`과 원하는 음악 파일 `bgm.mp3`를 저장소의 최상위 폴더에 업로드하세요.
GitHub → Settings → Pages → Deploy from a branch → main / (root).

## 배경음악
- 원하는 MP3 파일의 이름을 정확히 **`bgm.mp3`**로 바꿔 `index.html`과 같은 위치에 올립니다.
- 책 표지를 눌러 펼치면 음악이 재생됩니다. 화면 오른쪽 위의 업로드한 소리 켜기/음소거 이미지 버튼으로 끄고 켤 수 있습니다.
- 브라우저 정책상 음악은 페이지를 열자마자 재생되지 않고 처음 책을 넘기는 동작 이후 시작됩니다.
- MP3 파일은 저작권과 사용 허가를 확인하고 사용하세요.
- 이 ZIP에는 음악 파일이 포함되지 않았습니다.
